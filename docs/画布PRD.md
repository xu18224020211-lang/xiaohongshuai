# 画布（Designer）产品需求文档 PRD

> 适用系统：封面三层设计工具（小红书封面设计）
> 模块范围：前端画布 `/designer`（含左侧素材/AI 面板、中间画布、右侧图层面板、素材库弹框、保存/导出）
> 版本：v1.0（按当前已实现行为整理）　最后更新：2026-09-22

---

## 1. 概述

### 1.1 目标
让运营/设计人员在浏览器内完成「选模板 → 放素材 → AI 出背景与文字 → 导出封面」的全流程，不依赖 PS，且素材、模板、提示词全部由后台统一维护、可被超管在线改写。

### 1.2 核心概念
| 概念 | 说明 |
| --- | --- |
| 模板标签（模板类型） | 决定画布界面（A/B）、是否拼图、内置提示词、排序；由后台「模板 → 管理模板标签」维护 |
| 界面 A（底图界面） | 画布 = 底图 + 文字层 |
| 界面 B（产品 + AI 背景界面） | 画布 = 底图（AI 生成背景）/ 产品图 + 文字层 |
| 图1 | 模板预览图（参考图），只做参考与 AI 输入，不作为图层进入画布 |
| 图2 | 用户上传或从素材库选的底图 / 产品图 |
| 图层结构 | 场景底层（layer1）→ 产品中间层（layer2 / 拼图容器）→ 文字贴纸层（layer3，可多层） |
| 提示词 | 背景提示词、文字样式提示词（用户可编辑）+ 内置提示词（标签/模板配置，「修改」后展开可改） |

### 1.3 角色与权限（画布相关）
| 角色 | 画布能力 |
| --- | --- |
| 超管 / 高级管理者 / 部门主管 | 全部素材与模板可见；可在线修改任意提示语（悬停「修改」→「✓」保存） |
| 项目经理 | 权限内项目 + 通用素材/模板 |
| 部门成员 | 默认可查看所有项目素材与模板；被授予「素材/模板 修改」后可上传/修改 |
| 项目成员 | 自己项目 + 通用素材；后台可被授予模块权限 |

## 2. 页面结构

```
┌─────────────────────────────────────────────────────────────────────┐
│ 顶栏：← 返回 | 画布尺寸下拉 | 保存状态文字 · 保存按钮                │
├──────────────┬────────────────────────────────────┬─────────────────┤
│ 左 22rem     │ 画布区（自适应 + 20%~200% 缩放）    │ 右 20rem        │
│ 模板标签      │  · 图1 预览（右下角「换一个」）      │ 图层 / 素材 /   │
│ 上传/素材库   │  · 画布 Stage +「+」号按钮          │ 历史（3 个页签）│
│ 拼图容器      │  · 右侧工具栏（选择/历史/自由变换/   │                 │
│ 提示词 + 生成 │    橡皮擦）                         │                 │
└──────────────┴────────────────────────────────────┴─────────────────┘
```
- 桌面（≥1024px）：三栏常驻。
- 移动/窄屏：上=画布，下=标签页切换「素材 / AI」与「图层 / 贴纸 / 历史」。

## 3. 功能需求

### 3.1 模板标签与界面切换
| 编号 | 需求 | 细则 |
| --- | --- | --- |
| C-01 | 选择模板标签 | 下拉列出全部标签，A 类蓝色、B 类琥珀色区分；默认自动选中进入时所用模板的标签 |
| C-02 | 切换需确认 | **任一**标签切换（含同类内部）前，若画布已有内容，弹「切换界面」确认框：①保存并切换 ②不保存，直接切换 ③取消 |
| C-03 | 切换即清空 | 确认后清空图层与图片（layer1/layer2/拼图/文字层），并切到新标签的界面与提示词 |
| C-04 | 大字报类标签 | 不显示画布「+」号；左侧「上传素材 / 从素材库选择」置灰但仍可点击；底图位提示「可直接修改文案后生成」 |
| C-05 | 拼图标签 | 选中后画布立即出现拼图容器，默认 **4 拼图**；可切 2/3/4；切换非拼图标签自动移除容器 |
| C-06 | 当前界面提示 | 显示「当前界面：路径A · 底图 + 文字 / 路径B · 产品 + AI背景 + 文字」（文案可被超管修改） |

### 3.2 素材/图片放入画布
| 编号 | 需求 | 细则 |
| --- | --- | --- |
| C-10 | 上传素材 | 左侧「⬆ 上传素材」上传后：底图按画布高度等比铺满、水平居中；产品图按画布高度等比；上传同时写入素材库（类型 scene / product，带品牌） |
| C-11 | 从素材库选择 | 弹「从素材库选择」：默认显示**产品类**；第一排两个大类按钮（二选一），下方为该类下拉（产品类=品牌→类别→型号→标签，按品牌 2/3 级联动；贴图类=标签）；选中品牌后**靠右**出现「○ XXX项目专属」圆点勾选框；无「选择项目」下拉；每页 20 个 |
| C-12 | 画布「+」号 | 底图路径 1 个；拼图路径每空一格 1 个；点击弹「上传素材 / 从素材库选择」；已放入的格子不再显示「+」 |
| C-13 | 拼图上传 | 左侧每格「↑本地 / ↑素材库」，也支持一次多选依次填格；图片自动「最小铺满」格子并被裁剪在格内 |
| C-14 | 拼图张数 | 2/3/4 三种；4 拼图为 2×2 居中且不超宽；下方每格可「删除」 |
| C-15 | 立即显示控件 | 任何图片放入画布后**立即**显示白色变换控件（锁定图层除外） |

### 3.3 画布操作
| 编号 | 需求 | 细则 |
| --- | --- | --- |
| C-20 | 选择/变换 | 单击任一图即选中并显示变换控件；拖动移动，锚点缩放；「自由变换」开启=可非等比，关闭=等比 |
| C-21 | 控件样式 | 锚点/边框统一**白色**；控件放在裁剪区之外，贴到画布边缘也不会被裁掉 |
| C-22 | 旋转 | 元素与图层支持旋转（拼图格内图片不支持旋转） |
| C-23 | 橡皮擦 | 工具栏橡皮擦：擦产品图蒙版（滚轮调笔刷 8–240px，光标显示笔刷圈） |
| C-24 | 缩放 | 画布左下角 −/百分比/＋，范围 **20%–200%**；**Ctrl(⌘)+滚轮只缩放画布**（不触发浏览器缩放、不改笔刷） |
| C-25 | 画布尺寸 | 顶栏下拉：3:4 默认 / 小红书 1242×1656 / 4:3 / 1:1 / 2:3 / 16:9；切换后各图层按新高度等比自适应 |
| C-26 | 历史记录 | 最多 20 步，指针式：可跳转到任意一步且不丢失其它记录；不记录「切换界面、调整/移除拼图容器、改画布尺寸、切换拼图张数」等设置类操作 |
| C-27 | 锁定 | 图层/元素可锁定：锁定后不可拖动、不可删除（删除按钮置灰）、不显示变换控件；**仅最底层底图默认锁定** |
| C-28 | 显示/隐藏 | 每个图层有眼睛图标切换可见性 |

### 3.4 图层面板（右侧）
| 编号 | 需求 | 细则 |
| --- | --- | --- |
| C-30 | 顺序 | 上→下，最下为最底层；顶部=文字/贴纸（新增自动置顶），中部=产品层/拼图容器，底部=场景底层 |
| C-31 | 图层名称可改 | **双击**任意图层名称就地编辑，回车保存、Esc 取消（底图、产品层、拼图容器、每个文字/贴纸层） |
| C-32 | 删除 | 所有图层使用统一的删除图标（暗红）；锁定置灰不可点 |
| C-33 | 元素操作 | 文字/贴纸层：上移 / 下移 / 复制 |
| C-34 | 拼图格（选中格时） | 显示该格参数与「删除」本格按钮 |
| C-35 | 素材页签 | 与素材库同一数据源：第一排两个大类按钮，下拉在其下（窄栏分两行显示）；选中品牌后「○ XXX项目专属」勾选框**左对齐**；无「选择项目」下拉 |
| C-36 | 点选素材 | 点击素材 = **选用**：以「上面一层」加入画布，不删除已有图层；悬停只显示「选用」二字；成功后提示「已选用到画布上面一层」 |

### 3.5 AI 生成
| 编号 | 需求 | 细则 |
| --- | --- | --- |
| C-40 | 顺序 | 先生成背景，再生成文字样式；界面 B 才显示「背景提示词 + 生成含产品背景」区块 |
| C-41 | 提示词分组 | 「背景提示词」（始终显示）+「已内置背景提示词」（默认隐藏，点「修改」展开，展开后出现「隐藏」）；「AI文案内容（可修改）」+「已内置文字样式提示词」（同上） |
| C-42 | 严格分离 | 背景请求只发送「背景提示词 + 背景内置提示词」；文字请求只发送「文字样式提示词 + 文字内置提示词」，互不混入 |
| C-43 | 参考图 | 背景：产品图（layer2）为参考；文字：图1（模板预览）+ 图2（已生成背景优先，其次产品图） |
| C-44 | 出图尺寸 | 按画布宽高比推算（16 倍数，单边 ≤3840），生成后按画布高度等比放入画布 |
| C-45 | 等待态 | 生成中显示全屏遮罩「AI 生成中，请稍候… 约 20 秒 ~ 2 分钟」 |
| C-46 | 按钮下方说明 | 可被超管在线修改（悬停「修改」→ 输入 →「✓」保存） |
| C-47 | 未配置文字提示词 | 该标签未配置时提示：可在后台「模板 → 模板标签」里配置 |

### 3.6 图1 预览与「换一个」
| 编号 | 需求 | 细则 |
| --- | --- | --- |
| C-50 | 预览 | 选标签后自动展示该标签下第一个模板，右上角可关闭；尺寸随窗口缩放（≤30vh / ≤19vw） |
| C-51 | 换一个 | 图1 右下角红底【换一个】：在该标签下轮换下一个模板 |
| C-52 | 同步内容 | 换模板后：AI 文案内容、背景提示词按该模板后台配置更新；内置提示词按所属标签配置更新；若模板自身未配置则沿用标签配置 |
| C-53 | 单模板 | 该标签只有 1 个模板时提示「这类标签只有一个模板，换一个还是这个」，内容不变 |

### 3.7 保存与导出
| 编号 | 需求 | 细则 |
| --- | --- | --- |
| C-60 | 保存设计稿 | 顶栏「保存」→ 弹框填写名称（默认「未命名设计+日期+时间戳」，输入框为醒目可编辑态并自动聚焦全选）→ 确定保存 |
| C-61 | 保存动效 | 保存成功后：一个「设计稿」缩略块从画布中心缩小飞向**右上角头像**并淡出 |
| C-62 | 保存并切换 | 标签切换确认框选「保存并切换」时，先走同一命名弹框，保存成功后自动清空画布并切到新标签 |
| C-63 | 权限内落库 | 保存为「设计稿」写入历史记录（不写入模板库）；未选项目时自动落到自己权限内第一个项目 |
| C-64 | 未保存离开 | 返回首页时若有未保存内容，提示：保存并离开 / 不保存，直接离开 / 取消 |
| C-65 | 导出图片 | 右下「保存图片」→ 三个选项：① 最终合成图（PNG，含背景+产品+文字）② 背景图（只导出底图/拼图宫格）③ 文字样式 PNG（仅文字/贴纸，背景透明） |

### 3.8 提示语在线修改（超管）

| C-72 | 未登记兜底 | 未登记的文案键显示原始文案而不是键名 |
| C-73 | 大类名称 | 「产品类 / 贴图类」名称可在后台「管理素材标签 → 大类名称」修改，画布与弹框全部同步 |

## 4. 关键状态与边界

| 场景 | 期望行为 |
| --- | --- |
| 空画布 | 显示「+」号按钮（大字报显示底图位提示，无「+」） |
| 上传图片失败 | 面板顶部红色错误条提示，不阻塞其它操作 |
| 素材库无素材 | 显示「暂无素材」，计数为 0 |
| 锁定底图 | 无变换控件、删除按钮置灰、不可拖动；需先解锁 |
| 拼图格为空 | 该格半透明 + 虚线边框，画布中对应位置显示「+」 |
| 图片加载慢 | 选中后变换控件最多自动重试约 6 秒，加载完即绑定，保证「加图即出现控件」 |
| 提示词为空 | 未配置文字提示词时隐藏生成文字区块并给出后台配置指引 |

## 5. 数据结构（画布状态）

```ts
DesignState = {
  path: 'A' | 'B',                       // 界面
  canvasWidth, canvasHeight,             // 画布尺寸
  layer1: PlacedImage | null,            // 场景底层（默认锁定）
  layer2: PlacedImage | null,            // 产品中间层（默认不锁定）
  puzzle: PuzzleState | null,            // 拼图容器 { count(2|3|4), cells, name?, visible? }
  layer3: OverlayItem[],                 // 文字/贴纸层 { kind:'text'|'sticker', name?, x,y,w,h, rotation, opacity, locked, visible, z }
  selectedId: string | null,             // 'layer1' | 'layer2' | 'puzzle' | 'puzzle:N' | overlayId
  scenePrompt, textPrompt,               // 用户可编辑提示词
  tagScenePrompt, tagTextPrompt,         // 内置提示词（标签/模板配置）
  tagTypeId, designName, designId, projectId, templatePreview,
  brushMode: 'select' | 'erase', brushSize,
  freeTransform: boolean, zoom: number,  // 缩放 20~200
  undoSteps: UndoStep[], undoPos: number,
}
```

## 6. 非功能需求
1. **性能**：画布图片按需加载、异步绑定控件；上传图片分目录存放（assets/templates/misc + 月份），服务端定期清理未被引用的孤儿图。
2. **兼容**：桌面三栏 + 移动端上下布局；Ctrl+滚轮只在画布内生效。
3. **可用性**：所有破坏性操作（切换标签、离开页面、删除）都有二次确认或明确提示。
4. **可运营**：所有面向用户的提示语、大类名称均由超管在线修改，无需发版。

## 7. 验收清单（画布）
- [ ] 切换任一同类/跨类模板标签均提示保存，选「不保存」后画布图层与图片全部清空
- [ ] 底图、产品图、拼图任一格放入图片后立即出现白色变换控件，贴边不被裁切
- [ ] 拼图只传第 2/3/4 格也能显示该格控件
- [ ] 单击画布任一图立即出现控件；锁定图层无控件且删除置灰
- [ ] 右侧素材点选=选用（叠加到上层，不删除原有图层），悬停仅显示「选用」
- [ ] 素材库弹框默认产品类；品牌选中后出现「XXX项目专属」圆点勾选框
- [ ] 图1「换一个」后左侧 AI 文案内容与内置提示词同步后台配置
- [ ] 保存弹框默认名称为「未命名设计+日期+时间戳」且可编辑，保存后飞向头像动效
- [ ] Ctrl+滚轮只缩放画布，范围 20%–200%
- [ ] 所有图层名称可双击修改；删除图标统一
- [ ] 导出三种产物均正确（合成图 / 背景图 / 文字样式 PNG）
