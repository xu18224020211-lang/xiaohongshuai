# 封面三层设计工具 — 功能需求文档（模板 / 素材 / 画布）

> 用途：产品经理汇总功能需求用。本文按「前端用户侧」与「后台管理侧」两条线描述**已实现**的功能行为，可直接作为需求基线（Baseline）与迭代依据。
> 版本：v1.0　整理日期：2026-09-22
> 阅读方式：每个模块先看「功能定位」，再看表格里的功能点；标 ⚠️ 的是特例/易错点，标 🔜 的是建议后续补的需求。

---

## 0. 系统总览

**一句话定位**：运营/设计人员在浏览器内完成「选模板 → 放素材 → AI 出背景与文字 → 导出小红书封面」，素材、模板、提示词全部由后台统一维护。

**三块核心资产的关系**：

```
产品（品牌 → 类别 → 型号）           ← 归属骨架，素材/项目都挂在它下面
   └── 项目（可挂专属素材 / 专属模板） ← 权限与专属内容的边界
        ├── 素材（产品类 / 贴图类 + 标签）
        ├── 模板（按「模板标签」分类，可通用或项目专属）
        └── 设计稿（用户在画布保存的成品）

模板标签（模板类型） = 画布「玩法」的开关：决定界面 A/B、是否拼图、内置提示词、排序
```

**角色一览（与本文相关的部分）**

| 角色 | 能看 | 能改 |
| --- | --- | --- |
| 超管 | 全部 | 全部（含大类改名、提示语在线修改、回收站） |
| 高级管理者 / 部门主管 | 全部 | 素材/模板/项目（部门主管不能改项目元信息） |
| 项目经理 | 自己负责的项目 + 通用内容 | 权限内素材/模板 |
| 部门成员 | **默认可看全部项目/素材/模板**（只读） | 被授予「素材/模板 修改」后可改 |
| 项目成员 | 自己项目 + 通用内容 | 默认只读，后台可被单独勾选权限 |
| 普通用户 | 权限范围内只读 | 无 |

## 1. 模板模块

### 1.1 功能定位
模板 = 封面版式的「参考图 + 提示词」载体。用户不直接编辑模板，而是**选一个模板进入画布**，系统把该模板的提示词、所属标签的玩法（界面/拼图）一起带进画布。

### 1.2 前端·首页模板库

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| T-01 | 页面结构 | Hero 区（站点主标题/副标题、右上角两级筛选）→ **模板标签按钮行** → 模板卡片瀑布网格 |
| T-02 | 两级筛选 | 品牌下拉 → 项目下拉（级联：选了品牌只列该品牌项目）；只有 1 个可见项目时自动选中 |
| T-03 | 标签筛选 | 「全部模板」+ 各模板标签按钮，每个标签显示模板数量角标（无模板显示 0）；行尾显示「共 N 个模板」 |
| T-04 | 卡片内容 | 模板底图；左上角红色角标=模板标签名；右上角「XX项目专属」或「通用」；下方模板名称 + 文字样式提示词（2 行截断） |
| T-05 | 交互 | 点卡片进入画布；桌面端悬浮显示主按钮，移动端显示整宽按钮 |
| T-06 | 筛选规则 | 标签筛选 + 项目/品牌筛选**同时生效**；结果为空显示空状态文案 |
| T-07 | 分页 | ⚠️ **首页不做分页**，一次展示筛选结果全部卡片（建议量大后加分页/懒加载 🔜） |
| T-08 | 模板使用计数 | 从首页进入画布时会累加该模板的使用次数，后台仪表盘「模板使用排行」据此统计 |

### 1.3 后台·模板管理

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| T-10 | 列表与筛选 | 顶部按钮：回收站（仅超管）/ 管理模板标签 / 新建模板；筛选行 = 品牌 → 产品（类别）→ 项目 三个级联下拉 + 模板标签按钮 |
| T-11 | 卡片信息 | 3:4 预览框；左上标签名；右上「专属·项目名」或「通用」；下方名称 +「文字：提示词」+（B 类）「背景：提示词」 |
| T-12 | 分页 | 每页 **25** 个（5×5），页码最多显示 12 个 |
| T-13 | 批量操作 | 全选（本页）/ 批量修改 / 批量删除（二次确认） |
| T-14 | 悬浮操作 | 卡片悬浮出现「管理」按钮，打开「管理模板」弹框 |
| T-15 | **新建模板** | 字段顺序：模板标签 → 模板名称（选填）→（B 类标签）背景提示词 → 背景内置提示词（只读展示标签配置）→ 文字样式提示词 → 文字内置提示词（只读展示标签配置）→ **通用模板 / 项目专属模板** → 模板图片 |
| T-16 | 归属两步选 | ⚠️ 归属为**两步**：先选「品牌（产品）」，再选「该项目所属项目」；未选品牌时项目下拉禁用并提示「先选择品牌」；该品牌无项目时提示「只能保存为通用模板」 |
| T-17 | **管理模板** | 字段：底图（可上传替换 / 取消替换）、名称、模板标签、背景提示词、背景内置提示词、文字样式提示词、文字内置提示词、通用/项目专属（同样先品牌后项目） |
| T-18 | 内置提示词改回标签 | 管理员（超管/高级管理者/部门主管）可直接编辑内置提示词，保存时**同步写回该模板标签**（影响该标签下所有模板）；其他角色只读 |
| T-19 | 删除位置 | ⚠️ 删除按钮在弹框 **左下角**（红底「删除该模板」），列表行内不提供删除 |
| T-20 | 只读态 | 只有查看权限时弹框标题为「查看模板」，底部只有「关闭」 |
| T-21 | 回收站 | 模板删除进回收站（软删除），**36 小时**后连文件自动清理；仅超管可查看/恢复/彻底删除 |
| T-22 | 智能参考模板数量 | ⚠️ 「智能参考」标签下只允许存在 **1 个模板**；新建时若已存在会被拦截，提示去「管理模板」替换参考图 |

### 1.4 模板标签（后台「管理模板标签」）

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| T-30 | 标签字段 | 名称、画布界面（A 底图界面 / B 产品+AI背景界面）、是否拼图标签、默认文字样式提示词、默认背景提示词、排序 |
| T-31 | 新建 | 先填名称 + 选界面/拼图 → 填「背景提示词」→「文字样式提示词」（顺序固定：先背景后文字） |
| T-32 | 修改 | 行内编辑，字段同上；名称不可重复 |
| T-33 | 排序 | 每条标签有 ↑ ↓，调整后**新建/修改模板的标签顺序与画布中的标签顺序同步** |
| T-34 | 删除限制 | 标签下仍有模板时不允许删除，提示先迁移模板 |
| T-35 | 权限 | 仅超管/管理员可管理模板标签 |
| T-36 | ⚠️ 智能参考特例 | 该标签：① 永远排在最前（首页标签与卡片、画布下拉）② 只允许有 **1 个模板**（新建时拦截并提示去「管理模板」替换）③ 前端悬浮按钮文案改为「智能参考」④ 画布中**不提供「换一个」** |

### 1.5 模板 → 画布的数据传递

| 传递内容 | 说明 |
| --- | --- |
| 模板底图 | 作为画布「图1」参考预览（仅参考，不进入图层） |
| 文字样式提示词 | 作为画布「AI文案内容」初始值 |
| 背景提示词（B 类模板） | 作为画布「背景提示词」初始值 |
| 标签内置提示词 | 作为画布「已内置提示词」（可展开修改） |
| 标签界面 / 拼图 | 决定画布路径 A/B、是否显示拼图容器 |

## 2. 素材模块

### 2.1 功能定位
素材 = 可复用的图片资产库。用「两个大类 + 标签」组织：**产品类**（带品牌/产品/型号归属）与**贴图类**（只带标签）。

### 2.2 大类模型（核心规则）

| # | 规则 | 说明 |
| --- | --- | --- |
| A-01 | 只有两个大类 | 产品类 / 贴图类，二选一，互斥 |
| A-02 | 判定规则 | 产品类 =「产品图」类型的素材；贴图类 = **其余全部**（底图、贴纸等）。贴图类之下不再分素材类型 |
| A-03 | 大类名称可改 | 默认「产品类/贴图类」，**超管**可在「管理素材标签」里改名，前端画布同步 |
| A-04 | 标签分组 | 每个标签归属某个大类；下拉里只显示当前大类的标签 |
| A-05 | 项目专属勾选框 | 选中某品牌后，筛选条右侧出现「○ XX项目专属」圆点勾选框（数量与名称随该品牌下的项目）；未选品牌不显示；贴图类不显示 |

### 2.3 后台·素材管理

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| A-10 | 顶部按钮 | 回收站（仅超管）/ 管理素材标签 / 上传素材（无编辑权限时不显示） |
| A-11 | 筛选条 | 【产品类】【贴图类】+ 品牌→类别→型号→标签（父级未选则子级灰掉）+ 项目专属勾选框 + 「共 N 个 · 第 X/Y 页」 |
| A-12 | 卡片 | 3:4 图；左上「专属·项目名」或「通用」；右下归属名（型号/类别）；左下批量勾选框；下方大类角标 + 标签 |
| A-13 | 点卡片 | 打开「修改素材」弹框 |
| A-14 | 批量 | 全选（本页）/ 批量修改 / 批量删除 |
| A-15 | 分页 | 每页 **40** 个（8×5） |
| A-16 | 上传素材 | 大类（默认跟随当前筛选）→ 标签按钮（按大类）→ 归属（仅产品类：品牌→类别→型号）→ 通用/项目专属（仅产品类：**先品牌再项目**）→ 图片（**可多选**，逐张上传） |
| A-17 | 修改素材 | 大类 → 标签 → 归属型号 → 通用/项目专属（⚠️ **贴图类不显示「通用/项目专属」**）；左下角红色「删除该素材」；只读时标题为「查看素材」 |
| A-18 | 批量修改 | ⚠️ 大类**没有「不修改」选项**（一定会改成所选大类）；标签/归属/项目不选则保持原样；产品类可批量设为通用或某项目专属 |
| A-19 | 管理素材标签 | 顶部「大类名称」改名区（仅超管可编辑）+ 两组标签（产品类标签 / 贴图类标签）各自新建/修改/删除，显示每个标签下的素材数 |
| A-20 | 回收站 | 素材与模板两组；**36 小时**后连文件自动清理；仅超管可查看/恢复/彻底删除 |

### 2.4 前端画布·素材使用（两处入口）

| # | 入口 | 行为说明 |
| --- | --- | --- |
| A-30 | 「从素材库选择」弹框 | 默认**产品类**；同一套大类+下拉+项目专属勾选；每页 **20** 个（4×5）；卡片角标=素材类型、通用/专属；**点击即选用** |
| A-31 | 右侧「素材」页签 | 同一数据源；默认产品类；**无分页**一次展示；卡片左上大类角标、右上「专属」 |
| A-32 | 选用语义 | ⚠️ 点击素材 = **选用**：把它加到画布**最上面一层**，**不删除原有图层**；悬停只显示「选用」二字；贴纸类按画布宽 28% 缩放放入 |
| A-33 | 上传入口 | 画布左侧「上传素材」：上传的图同时写入素材库（之后可在右侧素材复用） |

### 2.5 素材可见性与文件规则

| # | 规则 | 说明 |
| --- | --- | --- |
| A-40 | 可见范围 | 通用素材对全部登录用户可见；项目专属素材只对有权访问该项目的人可见 |
| A-41 | 部门成员 | 默认可看**全部项目**素材与模板（只读）；被授予「素材/模板 修改」后可修改 |
| A-42 | 项目成员 | 只能看**自己项目**的素材 + 通用素材 |
| A-43 | 文件组织 | 上传文件按类型+月份分目录存放（素材 / 模板 / 其它），便于运维与迁移 |
| A-44 | 清理机制 | 删除进回收站，36 小时后连文件清理；系统定时清理没有被引用的孤儿图片（约 24 小时后） |

## 3. 画布模块

### 3.1 功能定位
画布 = 用户在模板基础上创作封面、AI 出图、导出成品的编辑工作台。三层结构：**底图（场景底层）→ 产品层 / 拼图容器 → 文字贴纸层**。

### 3.2 页面结构

```
┌───────────────────────────────────────────────────────────────┐
│ 顶栏：← 返回 | 画布尺寸 | 保存状态 · 保存                       │
├──────────────┬──────────────────────────────┬─────────────────┤
│ 左栏         │ 画布区                        │ 右栏            │
│ 模板标签      │  · 图1 预览（右下角「换一个」）│ 图层/素材/历史  │
│ 上传/素材库   │  · 画布 +「+」号按钮          │                 │
│ 拼图容器      │  · 右侧工具栏（选择/历史/自由 │                 │
│ 提示词+生成   │    变换/橡皮擦）              │                 │
└──────────────┴──────────────────────────────┴─────────────────┘
```

### 3.3 模板标签与界面

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| C-01 | 选择标签 | 下拉列出全部标签，A 类蓝色、B 类琥珀色区分 |
| C-02 | 切换需确认 | 画布已有内容时切换**任一**标签（含同类内部）都弹「切换界面」：保存并切换 / 不保存，直接切换 / 取消 |
| C-03 | 切换即清空 | 确认后清空全部图层与图片，切到新标签的界面与提示词 |
| C-04 | 大字报类特例 | 不显示画布「+」号；左侧上传/素材库按钮置灰但仍可点击；底图位提示「可直接修改文案后生成」 |
| C-05 | 拼图标签 | 选中后画布立即出现拼图容器，**默认 4 拼图**；可切 2/3/4；切到非拼图标签自动移除容器 |
| C-06 | 当前界面提示 | 显示「当前界面：路径A · 底图 + 文字 / 路径B · 产品 + AI背景 + 文字」 |

### 3.4 放图与画布操作

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| C-10 | 上传素材 | 底图/产品图上传后按画布高度等比铺满、水平居中 |
| C-11 | 从素材库选择 | 见素材模块 A-30 |
| C-12 | 画布「+」号 | 底图路径 1 个；拼图路径每空格 1 个；点击弹「上传素材 / 从素材库选择」；已放图的格子不再显示 |
| C-13 | 拼图上传 | 每格「↑本地 / ↑素材库」，支持多选依次填格；图片自动最小铺满并被裁剪在格内 |
| C-14 | 拼图格操作 | 每格下方按钮为「删除」 |
| C-15 | 立即显示控件 | ⚠️ 任何图片放入画布后**立即**出现白色变换控件（锁定图层除外）；加载慢时自动重试 |
| C-20 | 选择/变换 | 单击任一图即选中并显示变换控件；拖动移动、锚点缩放；自由变换开=可非等比，关=等比 |
| C-21 | 控件样式 | 锚点与边框统一**白色**，且贴到画布边缘不会被裁掉 |
| C-22 | 旋转 | 元素与图层支持旋转（拼图格内图片不支持） |
| C-23 | 橡皮擦 | 擦产品图蒙版，滚轮调笔刷大小（8–240px） |
| C-24 | 缩放 | 左下角 −/百分比/＋，范围 **20%–200%**；Ctrl+滚轮**只缩放画布** |
| C-25 | 画布尺寸 | 3:4 默认 / 小红书 1242×1656 / 4:3 / 1:1 / 2:3 / 16:9；切换后图层按新高度等比自适应 |
| C-26 | 历史记录 | 最多 20 步，可跳转任意一步且不丢其它记录；不记录「切换界面、调整拼图容器、改画布尺寸」等设置类操作 |
| C-27 | 锁定 | 锁定后不可拖动、不可删除（删除置灰）、不显示变换控件；仅最底层底图默认锁定 |
| C-28 | 显示/隐藏 | 每个图层可用眼睛图标切换可见性 |

### 3.5 图层面板（右栏）

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| C-30 | 顺序 | 上→下，最下为最底层；顶部=文字/贴纸（新增置顶），中部=产品层/拼图容器，底部=场景底层 |
| C-31 | 图层改名 | **双击图层名称**就地编辑，回车保存、Esc 取消（底图、产品层、拼图容器、每个文字/贴纸层都支持） |
| C-32 | 删除 | 所有图层使用统一的删除图标；锁定置灰不可点 |
| C-33 | 元素操作 | 文字/贴纸层支持上移 / 下移 / 复制 |
| C-34 | 素材页签 | 见素材模块 A-31 / A-32 |

### 3.6 AI 生成

| # | 功能点 | 行为说明 |
| --- | --- | --- |
| C-40 | 生成顺序 | **先生成背景，再生成文字样式**；界面 B 才显示背景生成区块 |
| C-41 | 提示词分组 | 「背景提示词」（始终显示）+「已内置背景提示词」（默认隐藏，点「修改」展开，展开后有「隐藏」）；「AI文案内容（可修改）」+「已内置文字样式提示词」（同上） |
| C-42 | ⚠️ 严格分离 | 背景请求只发「背景提示词 + 背景内置提示词」；文字请求只发「文字样式提示词 + 文字内置提示词」，两者互不混入 |
| C-43 | 参考图 | 背景：产品图；文字：图1（模板预览）+ 图2（已生成背景优先，其次产品图） |

## 4. 关键规则汇总（给 PM 划重点）

1. **素材大类的判定是「是不是产品图」**：产品类=产品图，贴图类=其余全部（底图/贴纸）。运营沟通时建议统一口径，避免「底图算哪类」的反复确认。
2. **通用 vs 项目专属**：素材和模板都遵循「通用（所有人）+ 项目专属（该项目成员）」；归属一律**先品牌后项目**两步选。
3. **专属内容的可见性**：项目成员只能看自己项目 + 通用；部门成员默认能看全部（只读）。
4. **删除一律二次确认 + 进回收站**，36 小时后连文件清理；回收站仅超管可操作。
5. **提示词顺序不可乱**：先生成背景、再生成文字；两段提示词严格分离发送。
6. **内置提示词双通道**：标签级（影响该标签下所有模板）与模板级（只影响该模板）；管理员在模板弹框改内置提示词会写回标签，需谨慎。
7. **智能参考是唯一特例标签**：排第一、只允许 1 个模板、画布不能换一个。
8. **画布「选用」不是「替换」**：点素材只往最上层叠加，不会删除已有图层。
